# Rocket.Chat Project Overview

## What is Rocket.Chat?

Rocket.Chat is an **open-source, secure, fully customizable communications platform** developed in TypeScript for organizations with high standards of data protection.

### Key Features
- **Team collaboration**: Secure internal and cross-company collaboration with role-based access control
- **Omnichannel citizen engagement**: Digital interactions across platforms like WhatsApp, SMS, and more
- **Optimization**: Self-hosted AI and customizable accessible workspace
- **Extensibility**: Apps marketplace, custom app development, platform embedding

### Scale & Usage
- Tens of millions of users daily
- 150+ countries
- Trusted by organizations like Deutsche Bahn, US Navy, Credit Suisse

### Repository Information
- **GitHub**: https://github.com/RocketChat/Rocket.Chat

## Project Purpose

The ultimate secure open-source solution for team communications, enabling:
- Real-time conversations between colleagues
- Cross-company communication
- Customer/citizen engagement
- Completely private and secure communications
- Increased productivity and user satisfaction
